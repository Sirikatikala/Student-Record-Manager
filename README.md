# Student Record Manager

## Description
A Python-based Student Record Manager that allows users to add,
validate, save, and read student records.

## Features
- Add Student
- Validate Email using Regex
- Save Student Data to File
- Read Student Data
- Handle Invalid Input using Exceptions

## Technologies Used
- Python
- Regular Expressions
- File Handling
- Exception Handling

## How to Run

Run the following command:

python student_record_manager.py
